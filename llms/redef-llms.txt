# REDEF

> REDEF is a media curation company founded and led by Jason Hirschhorn (CEO + Chief Curator) that "DJs the internet" — hand-picked daily remixes of the stories, people and ideas that matter across Media, Fashion, Music, Sports and Tech, delivered as Mixes, Sets, Originals, Charts and email Newsletters. REDEF publishes a consumer content website and email newsletters only: as of 2026-08-13 there is no developer program, no API, no documentation portal and no machine-readable API contract on any REDEF host.

## Status

- No public API. Probes on 2026-08-13 of `/openapi.json`, `/openapi.yaml`, `/swagger.json`, `/v1/openapi.json`, `/api-docs`, `/docs`, `/redoc`, `/graphql`, `/llms.txt`, `/api`, `/api/v1` and every `/.well-known/*` path on redef.com all returned the site's HTML catch-all page (HTTP 200, 504,882 bytes, identical to `/`) — soft 404s, not documents.
- No API subdomain: `api.redef.com`, `developer.redef.com`, `docs.redef.com`, `status.redef.com` and `mcp.redef.com` are all NXDOMAIN.
- The one machine-readable document REDEF serves is an OpenSearch 1.1 description at https://redef.com/open_search.xml, which describes the site's HTML article search, not an API.
- The REDEF GitHub organization (https://github.com/REDEF) holds a single forked repository (`ejsify`, a Browserify EJS precompiler, last pushed 2015) — no first-party SDK, client library or spec.
- No first-party packages found on npm, PyPI, RubyGems, crates.io, NuGet, Maven Central or pkg.go.dev.
